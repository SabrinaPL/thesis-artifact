## `terraform/main.tf`
```hcl
########################
# Provider configuration
########################
provider "openstack" {
  # Using clouds.yaml avoids hardcoding secrets in Terraform variables/state.
  #
  # Create ~/.config/openstack/clouds.yaml and set:
  #   cloud = "mycloud"
  #
  # If your OpenStack requires region, set var.region too.
  cloud  = var.cloud
  region = var.region
}

########################
# Look up required data
########################

# Find the tenant network by name so we can attach the VM NIC to it.
data "openstack_networking_network_v2" "tenant_net" {
  name = var.network_name
}

# Optional: external network used to allocate floating IPs.
data "openstack_networking_network_v2" "external" {
  count = var.allocate_floating_ip ? 1 : 0
  name  = var.external_network_name
}

########################
# Security group rules
########################

resource "openstack_networking_secgroup_v2" "web" {
  name        = var.security_group_name
  description = "Web server SG: allow SSH(22) and HTTP(80)."
}

# Allow SSH only from allowed CIDRs.
resource "openstack_networking_secgroup_rule_v2" "ingress_ssh" {
  for_each          = toset(var.ssh_allowed_cidrs)
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 22
  port_range_max    = 22
  remote_ip_prefix  = each.value
  security_group_id = openstack_networking_secgroup_v2.web.id
}

# Allow HTTP from anywhere (typical for a public web server).
resource "openstack_networking_secgroup_rule_v2" "ingress_http" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 80
  port_range_max    = 80
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web.id
}

# Egress: allow outbound traffic (updates, package downloads, etc.).
# Some OpenStack environments default-allow egress; others are stricter.
resource "openstack_networking_secgroup_rule_v2" "egress_all" {
  direction         = "egress"
  ethertype         = "IPv4"
  protocol          = null
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web.id
}

########################
# Compute instance
########################
resource "openstack_compute_instance_v2" "web" {
  name        = var.instance_name
  image_name  = var.image_name
  flavor_name = var.flavor_name

  # Inject the OpenStack keypair so we can SSH in.
  key_pair = var.ssh_key_name

  network {
    uuid = data.openstack_networking_network_v2.tenant_net.id
  }

  # Attach our security group by name.
  security_groups = [openstack_networking_secgroup_v2.web.name]

  # Good practice: make creates and updates safer.
  lifecycle {
    create_before_destroy = true
  }
}

########################
# Floating IP (optional)
########################
resource "openstack_networking_floatingip_v2" "fip" {
  count = var.allocate_floating_ip ? 1 : 0

  # Many OpenStack clouds still use "pool" with the external network name.
  pool = data.openstack_networking_network_v2.external[0].name
}

resource "openstack_compute_floatingip_associate_v2" "assoc" {
  count = var.allocate_floating_ip ? 1 : 0

  floating_ip = openstack_networking_floatingip_v2.fip[0].address
  instance_id = openstack_compute_instance_v2.web.id
}
```

# Ansible

## `ansible/site.yml`
```yaml
---
- name: Configure web server with nginx
  hosts: web
  become: true

  vars:
    # Keep configuration as variables (easier to change, easier to reuse).
    web_root: /var/www/html
    index_file: "{{ web_root }}/index.html"
    site_title: "Hello from OpenStack + Terraform + Ansible"
    listen_port: 80

  pre_tasks:
    # Wait for SSH to become available after VM boot/cloud-init.
    - name: Wait for SSH to be ready
      ansible.builtin.wait_for_connection:
        timeout: 300

    - name: Gather facts (needed to detect OS family)
      ansible.builtin.setup:

  tasks:
    - name: Install nginx on Debian/Ubuntu
      ansible.builtin.apt:
        name: nginx
        state: present
        update_cache: true
      when: ansible_facts.os_family == "Debian"

    - name: Install nginx on RHEL/Rocky/CentOS
      ansible.builtin.yum:
        name: nginx
        state: present
      when: ansible_facts.os_family == "RedHat"

    - name: Ensure nginx is enabled and running (systemd service)
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

    - name: Ensure web root exists
      ansible.builtin.file:
        path: "{{ web_root }}"
        state: directory
        mode: "0755"

    - name: Deploy static index.html
      ansible.builtin.copy:
        dest: "{{ index_file }}"
        mode: "0644"
        content: |
          <!doctype html>
          <html>
            <head>
              <meta charset="utf-8" />
              <title>{{ site_title }}</title>
            </head>
            <body>
              <h1>{{ site_title }}</h1>
              <p>Served by nginx on port {{ listen_port }}.</p>
            </body>
          </html>
      notify: Reload nginx

    # By default nginx already listens on 80, but we show how to enforce it.
    - name: Ensure nginx listens on port 80 on Debian-based distros
      ansible.builtin.lineinfile:
        path: /etc/nginx/sites-available/default
        regexp: '^\s*listen\s+'
        line: "        listen {{ listen_port }};"
      when: ansible_facts.os_family == "Debian"
      notify: Reload nginx

  handlers:
    # Handlers run only when notified (idempotent + avoids unnecessary reloads).
    - name: Reload nginx
      ansible.builtin.service:
        name: nginx
        state: reloaded
```


## Configure the server (Ansible)
Create inventory from Terraform outputs:
```bash
cd ../terraform
WEB_HOST="$(terraform output -raw public_ip)"
SSH_USER="$(terraform output -raw ssh_user)"
PRIVATE_KEY_PATH="$(terraform output -raw private_key_path)"

cd ../ansible
sed \
  -e "s|\${WEB_HOST}|$WEB_HOST|g" \
  -e "s|\${SSH_USER}|$SSH_USER|g" \
  -e "s|\${PRIVATE_KEY_PATH}|$PRIVATE_KEY_PATH|g" \
  inventory.ini.tmpl > inventory.ini
```

Run the playbook:
```bash
ansible-playbook -i inventory.ini site.yml
```

## Verify HTTP access

```
# Evaluation + Improvements Explained (what changed and why)

1. **Credential handling (security)**
   - **Problem in original**: Passing `user_name/password/auth_url` as Terraform variables often leads to secrets in `.tfvars`, shells, CI logs, and sometimes state/plan artifacts.
   - **Fix**: Switched to `provider "openstack" { cloud = var.cloud }` so credentials live in `clouds.yaml` (or env), not in Terraform code.
   - **Benefit**: Stronger secret hygiene; aligns with “don’t hardcode credentials”.

2. **Restrict SSH exposure (security)**
   - **Problem**: SSH rule allowed `0.0.0.0/0` with no easy way to tighten.
   - **Fix**: Added `ssh_allowed_cidrs` variable and used `for_each` to generate one rule per CIDR.
   - **Benefit**: Encourages least privilege. Beginners learn to avoid “open SSH to the world”.

3. **Egress rule clarity (operability)**
   - **Problem**: Some OpenStack clouds default-deny egress or have policy changes; leaving it implicit can break `apt/yum`.
   - **Fix**: Added `egress_all` rule (IPv4) explicitly.
   - **Benefit**: More predictable behavior for package installation.

4. **More reliable outputs (correctness)**
   - **Problem**: `access_ip_v4` is frequently empty on OpenStack; output could mislead users.
   - **Fix**: Output `addresses` (authoritative) + `public_ip` for floating IP.
   - **Benefit**: Easier debugging and fewer “why is fixed_ip empty?” issues.

5. **Ansible readiness + idempotence (quality)**
   - **Problem**: Ansible may run before SSH is ready, causing flaky first runs.
   - **Fix**: Added `wait_for_connection` in `pre_tasks`.
   - **Benefit**: More reliable automation.

6. **Beginner-friendly comments + best-practice nudges (maintainability)**
   - Added inline explanations about:
     - why `clouds.yaml` is preferred,
     - why variables exist,
     - what handlers do,
     - why we use `terraform fmt`/`validate`.
```
