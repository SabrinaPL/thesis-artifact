## Query

    Task:

    Generate an Infrastructure-as-Code solution that provisions and configures a single web server on an OpenStack cloud platform.

    Requirements:

    Infrastructure (Terraform):

    Provision one virtual machine instance

    Configure a security group to allow:
    * Inbound SSH (port 22)
    * Inbound HTTP (port 80)

    Use variables for:
    * SSH key name
    * Path to private key (identity file)

    Configuration (Ansible):

    Install nginx using the system package manager

    Configure nginx to:
    * Run as a system service
    * Listen on port 80
    * Deploy a static HTML file at '/var/www/html/index.html'

    Constraints:

    * Do not hardcode credentials, SSH keys, or user-specific values
    * All configurable values must be defined as variables

    Output Format:

    * Terraform configuration files
    * Ansible playbook
    * Instructions to execute deployment and verify access via HTTP

### `terraform/main.tf`

```hcl
data "openstack_networking_network_v2" "net" {
  name = var.network_name
}

data "openstack_images_image_v2" "image" {
  name        = var.image_name
  most_recent = true
}

resource "openstack_networking_secgroup_v2" "web_sg" {
  name        = "${var.instance_name}-sg"
  description = "Allow SSH and HTTP"
}

resource "openstack_networking_secgroup_rule_v2" "ssh_in" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 22
  port_range_max    = 22
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web_sg.id
}

resource "openstack_networking_secgroup_rule_v2" "http_in" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 80
  port_range_max    = 80
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web_sg.id
}

resource "openstack_compute_instance_v2" "web" {
  name            = var.instance_name
  image_id        = data.openstack_images_image_v2.image.id
  flavor_name     = var.flavor_name
  key_pair        = var.ssh_key_name
  security_groups = [openstack_networking_secgroup_v2.web_sg.name]

  network {
    uuid = data.openstack_networking_network_v2.net.id
  }
}

# Optional: allocate + associate a floating IP for public access
data "openstack_networking_network_v2" "external" {
  count = var.create_floating_ip ? 1 : 0
  name  = var.external_network_name
}

resource "openstack_networking_floatingip_v2" "fip" {
  count = var.create_floating_ip ? 1 : 0
  pool  = data.openstack_networking_network_v2.external[0].name
}

resource "openstack_compute_floatingip_associate_v2" "fip_assoc" {
  count       = var.create_floating_ip ? 1 : 0
  floating_ip = openstack_networking_floatingip_v2.fip[0].address
  instance_id = openstack_compute_instance_v2.web.id
}

locals {
  instance_ip = var.create_floating_ip ? openstack_networking_floatingip_v2.fip[0].address : openstack_compute_instance_v2.web.access_ip_v4
}
```

### `ansible/site.yml`

```yaml
---
- name: Configure web server
  hosts: web
  become: true
  vars_files:
    - variables.yml

  tasks:
    - name: Install nginx
      ansible.builtin.package:
        name: nginx
        state: present
        update_cache: true

    - name: Ensure web root exists
      ansible.builtin.file:
        path: '{{ web_root }}'
        state: directory
        owner: root
        group: root
        mode: '0755'

    - name: Deploy static index.html
      ansible.builtin.copy:
        dest: '{{ index_file }}'
        content: '{{ index_content }}'
        owner: root
        group: root
        mode: '0644'

    - name: Ensure nginx is enabled and running
      ansible.builtin.service:
        name: nginx
        enabled: true
        state: started
```

## How to run

### 1) Prereqs

- Terraform installed
- Ansible installed
- OpenStack credentials set **without hardcoding** (recommended: `clouds.yaml` + `OS_CLIENT_CONFIG_FILE` or standard `OS_...` env vars)

Example (recommended):

- Create `~/.config/openstack/clouds.yaml` with a `cloud:` entry (outside this repo, do not commit).
- Ensure the referenced keypair (`ssh_key_name`) already exists in OpenStack.

### 2) Terraform apply

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your values

terraform init
terraform apply
```

Get the target IP:

```bash
terraform output -raw instance_ip
terraform output -raw ssh_user
terraform output -raw private_key_path
```

### 3) Create a temporary Ansible inventory from Terraform outputs

From `terraform/`:

```bash
IP="$(terraform output -raw instance_ip)"
USER="$(terraform output -raw ssh_user)"
KEY="$(terraform output -raw private_key_path)"

cat > ../ansible/inventory.ini <<EOF
[web]
${IP}

[web:vars]
ansible_user=${USER}
ansible_ssh_private_key_file=${KEY}
ansible_ssh_common_args=-o StrictHostKeyChecking=no
EOF
```

### 4) Run Ansible

```bash
cd ../ansible
ansible-playbook -i inventory.ini site.yml
```
