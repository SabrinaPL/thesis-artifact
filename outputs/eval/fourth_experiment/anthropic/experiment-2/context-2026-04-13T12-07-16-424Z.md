# Summary: Infrastructure as Code (IaC) Best Practices with Terraform and Ansible

## Core Value of IaC

Infrastructure as Code (IaC) replaces manual "ClickOps" processes with machine-readable configuration files, delivering value across key dimensions:

- **Repeatability**: Using the same configuration files across development, staging, and production ensures identical infrastructure and eliminates environment drift by design.
- **Audibility**: Every change is a Git commit, providing a permanent record of who changed what, when, and why.

## Terraform Best Practices

1. **Use version control and prevent manual changes**: Treat infrastructure configurations as application code. Embrace a GitOps approach and implement automated CI/CD workflows to apply changes.

2. **Shift culture to collaborative IaC**: Enable self-service infrastructure across teams, apply policies and compliance standards, and leverage relevant insights. Keep infrastructure in version-controlled repositories as the foundation for improving manual infrastructure management.

3. **Code quality tooling**: Use `terraform fmt` and `terraform validate` as part of your workflow. Run CI plans with human approval before applying changes.

4. **Provisioners**: Terraform is primarily designed for immutable infrastructure. Use purpose-built solutions for post-apply operations (uploading files, running commands/scripts) whenever possible. Only fall back to Terraform provisioners when no provider-native mechanism exists.

## Ansible for IaC

Ansible supports **mutable infrastructure**, where changes are applied directly to existing systems. This offers flexibility for rapid changes but can accumulate configuration drift. Organizations can address drift through periodic playbook execution and monitoring.

Ansible can provision cloud infrastructure on AWS, including VPC networking, security groups, EC2 instances, Application Load Balancers, and Nginx web server deployment. Clean up resources after use:

```
ansible-playbook playbooks/teardown yml
```

## Multi-Tool Orchestration

Platforms like Spacelift can manage infrastructure tools including Ansible, Terraform, OpenTofu, Pulumi, AWS CloudFormation, and Kubernetes from a single place, combining stacks and building workflows across tools with GitOps flows and compliance checks.
