# Retrieval Context

## Prompt Label
SECOND_EXPERIMENT

## Model
openai

OpenStack Neutron security groups in Terraform are managed with `openstack_networking_secgroup_v2`, while individual rules are managed separately with `openstack_networking_secgroup_rule_v2`. Unlike Nova security groups, Neutron separates the security group resource from its rules.

A security group can be created with a required `name`, optional `description`, optional `tenant_id`, optional `region`, and `delete_default_rules` to control whether default egress rules should be removed. By default, many OpenStack environments create egress rules automatically for new security groups, typically for both IPv4 and IPv6. These default rules are not managed by Terraform unless you set `delete_default_rules = true` and recreate the desired rules explicitly. Cloud behavior may vary: some environments add extra default rules, and some may add none.

Example rule creation for explicit management:

```hcl
resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v4" {
  direction = "egress"
  ethertype = "IPv4"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v6" {
  direction = "egress"
  ethertype = "IPv6"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}
```

Example ingress rule for SSH:

```hcl
resource "openstack_networking_secgroup_v2" "secgroup_1" {
  name = "secgroup_1"
  description = "My neutron security group"
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_1" {
  direction = "ingress"
  ethertype = "IPv4"
  protocol = "tcp"
  port_range_min = 22
  port_range_max = 22
  remote_ip_prefix = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.secgroup_1.id
}
```

Security groups can also be imported by ID:

```bash
$ terraform import openstack_networking_secgroup_v2 secgroup_1 38809219-5e8a-4852-9139-6f461c90e8bc
```

The provider itself must be configured with valid OpenStack credentials and region information before these resources can be used.
