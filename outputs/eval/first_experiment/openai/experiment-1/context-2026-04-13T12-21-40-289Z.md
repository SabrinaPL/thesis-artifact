# Retrieval Context

## Prompt Label
FIRST_EXPERIMENT

## Model
openai

In Terraform OpenStack, `openstack_networking_secgroup_v2` manages the Neutron security group itself, while `openstack_networking_secgroup_rule_v2` manages individual rules. Neutron security groups and rules are separate resources.

A key behavior is that many OpenStack environments automatically create default **egress** rules when a new security group is created. These auto-created rules are typically **not managed by Terraform**. If you want Terraform to fully control the security group rules, set `delete_default_rules = true` on the security group and then explicitly define the egress rules yourself. This behavior can vary by cloud: some OpenStack deployments may add more default rules, and some may add none.

Example from the provider docs:

```hcl
resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v4" {
  direction = "egress"
  ethertype = "IPv4"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v6" {
  direction = "egress"
  ethertype = "IPv6"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}
```

Example ingress rule resource:

```hcl
resource "openstack_networking_secgroup_v2" "secgroup_1" {
  name = "secgroup_1"
  description = "My neutron security group"
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_1" {
  direction = "ingress"
  ethertype = "IPv4"
  protocol = "tcp"
  port_range_min = 22
  port_range_max = 22
  remote_ip_prefix = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.secgroup_1.id
}
```

Relevant arguments shown in the retrieved docs:
- Security group: `name`, `description`, `tenant_id`, `region`, `delete_default_rules`
- Security group rule: `direction`, `ethertype`, `protocol`, `port_range_min`, `port_range_max`, `remote_ip_prefix`, `remote_group_id`, `remote_address_group_id`, `security_group_id`, `tenant_id`, `region`, `description`

The OpenStack Nova documentation also shows that newly created security groups commonly include default IPv4 and IPv6 egress rules, which aligns with the Terraform provider note.
