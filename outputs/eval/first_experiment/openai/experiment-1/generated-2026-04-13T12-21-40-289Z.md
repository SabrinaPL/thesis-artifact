## `main.tf`

```hcl
resource "openstack_networking_secgroup_v2" "web" {
  name                 = "${var.instance_name}-sg"
  description          = "Security group for web server"
  delete_default_rules = true
}

resource "openstack_networking_secgroup_rule_v2" "egress_ipv4" {
  direction         = "egress"
  ethertype         = "IPv4"
  security_group_id = openstack_networking_secgroup_v2.web.id
}

resource "openstack_networking_secgroup_rule_v2" "egress_ipv6" {
  direction         = "egress"
  ethertype         = "IPv6"
  security_group_id = openstack_networking_secgroup_v2.web.id
}

resource "openstack_networking_secgroup_rule_v2" "ssh_ingress" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 22
  port_range_max    = 22
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web.id
  description       = "Allow SSH"
}

resource "openstack_networking_secgroup_rule_v2" "http_ingress" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 80
  port_range_max    = 80
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.web.id
  description       = "Allow HTTP"
}

resource "openstack_compute_instance_v2" "web" {
  name            = var.instance_name
  image_name      = var.image_name
  flavor_name     = var.flavor_name
  key_pair        = var.ssh_key_name
  security_groups = [openstack_networking_secgroup_v2.web.name]

  network {
    name        = var.network_name
    fixed_ip_v4 = var.instance_fixed_ip_v4
  }
}

resource "openstack_networking_floatingip_v2" "web" {
  pool = var.floating_network_name
}

resource "openstack_compute_floatingip_associate_v2" "web" {
  floating_ip = openstack_networking_floatingip_v2.web.address
  instance_id = openstack_compute_instance_v2.web.id
}

resource "local_file" "ansible_inventory" {
  filename = "${path.module}/inventory.ini"
  content  = <<-EOT
    [web]
    ${openstack_networking_floatingip_v2.web.address} ansible_user=${var.ssh_user} ansible_ssh_private_key_file=${var.private_key_path}
  EOT
}

resource "local_file" "web_content" {
  filename = "${path.module}/generated-index.html"
  content  = var.web_content
}
```

# Ansible playbook

## `playbook.yml`

```yaml
---
- name: Configure OpenStack web server
  hosts: web
  become: true
  vars:
    nginx_package: nginx
    nginx_service: nginx
    web_root: /var/www/html
    index_file: /var/www/html/index.html
    local_index_src: ./generated-index.html

  tasks:
    - name: Wait for SSH to become available
      ansible.builtin.wait_for_connection:
        timeout: 300

    - name: Install nginx
      ansible.builtin.package:
        name: "{{ nginx_package }}"
        state: present

    - name: Ensure web root exists
      ansible.builtin.file:
        path: "{{ web_root }}"
        state: directory
        mode: "0755"

    - name: Deploy static HTML page
      ansible.builtin.copy:
        src: "{{ local_index_src }}"
        dest: "{{ index_file }}"
        owner: root
        group: root
        mode: "0644"

    - name: Ensure nginx service is enabled and started
      ansible.builtin.service:
        name: "{{ nginx_service }}"
        enabled: true
        state: started
```

# Instructions to execute deployment

## 1. Prepare files

Create a working directory and place all Terraform files plus the Ansible playbook into it.

Copy the example variable file:

```bash
cp terraform.tfvars.example terraform.tfvars
```

Then edit `terraform.tfvars` with your real OpenStack values.

---

## 2. Initialize Terraform

```bash
terraform init
```

---

## 3. Review the plan

```bash
terraform plan
```

---

## 4. Apply the infrastructure

```bash
terraform apply
```

Approve when prompted.

This will:

- create the security group
- add explicit egress rules
- add ingress rules for:
  - TCP 22
  - TCP 80
- create the VM
- allocate and associate a floating IP
- generate:
  - `inventory.ini`
  - `generated-index.html`

---

## 5. Run Ansible

Once Terraform completes:

```bash
ansible-playbook -i inventory.ini playbook.yml
```

# Verify access

## Verify SSH

```bash
ssh -i ~/.ssh/id_rsa <ssh_user>@<floating_ip>
```

Replace:

- `~/.ssh/id_rsa` with your private key path
- `<ssh_user>` with your configured `ssh_user`
- `<floating_ip>` with the Terraform output

Or get the IP with:

```bash
terraform output floating_ip
```

```bash
curl http://$(terraform output -raw floating_ip)
```

You should see the HTML content configured in `web_content`.

You can also open in a browser:

```text
http://<floating_ip>
```

# Notes

## About security group rules
OpenStack often auto-creates default egress rules for new security groups. Since Terraform does not necessarily manage those automatically created rules, this example uses:

```hcl
delete_default_rules = true
```

Then it explicitly defines IPv4 and IPv6 egress rules, so Terraform fully controls the rule set.

## About SSH user
The SSH username depends on the image. Common values include:

- `ubuntu`
- `debian`
- `centos`
- `cloud-user`

Set it via the `ssh_user` variable.

## About package manager
The Ansible `package` module uses the system package manager automatically, satisfying the requirement to install nginx through the OS package manager.
