# Summary: OpenStack Security Groups and Rules in Terraform

## Security Group Resource (`openstack_networking_secgroup_v2`)

This resource manages Neutron security groups in OpenStack. Key arguments include:

- **name** (Required) - Unique name for the security group
- **description** (Optional) - Description of the security group
- **tenant_id** (Optional) - Owner of the security group; required if an admin creates it for another tenant
- **delete_default_rules** (Optional) - Whether to delete the default egress security rules
- **region** (Optional) - Region for the networking client; defaults to the provider's region

## Security Group Rule Resource (`openstack_networking_secgroup_rule_v2`)

This resource manages individual Neutron security group rules, which are separate from the group itself. Key arguments include:

- **direction** - `ingress` or `egress`
- **ethertype** - `IPv4` or `IPv6`
- **protocol** - e.g., `tcp`
- **port_range_min** / **port_range_max** - Port range
- **remote_ip_prefix** - CIDR for allowed remote IPs
- **remote_group_id** - OpenStack ID of a remote security group (same tenant)
- **security_group_id** - The security group this rule belongs to
- **description**, **region**, **tenant_id** - Optional fields

## Default Egress Rules

By default, OpenStack creates egress rules (IPv4 and IPv6) for each new security group. These are **not managed by Terraform**. To have Terraform fully manage all rules, set `delete_default_rules = true` on the security group and explicitly recreate them:

```
resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v4" {
  direction         = "egress"
  ethertype         = "IPv4"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_v6" {
  direction         = "egress"
  ethertype         = "IPv6"
  security_group_id = openstack_networking_secgroup_v2.secgroup.id
}
```

Note: Default rule behavior may vary depending on the OpenStack cloud configuration.

## Example: Security Group with SSH Ingress Rule

```
resource "openstack_networking_secgroup_v2" "secgroup_1" {
  name        = "secgroup_1"
  description = "My neutron security group"
}

resource "openstack_networking_secgroup_rule_v2" "secgroup_rule_1" {
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 22
  port_range_max    = 22
  remote_ip_prefix  = "0.0.0.0/0"
  security_group_id = openstack_networking_secgroup_v2.secgroup_1.id
}
```

## Import

Security groups and rules can be imported by ID:

```
$ terraform import openstack_networking_secgroup_v2 secgroup_1 38809219-5e8a-4852-9139-6f461c90e8bc
```

## Provider Configuration

The OpenStack Terraform provider requires authentication credentials:

```
provider "openstack" {
  user_name   = "admin"
  tenant_name = "admin"
  password    = "pwd"
  auth_url    = "http://myauthurl:5000/v3"
  region      = "RegionOne"
}
```
