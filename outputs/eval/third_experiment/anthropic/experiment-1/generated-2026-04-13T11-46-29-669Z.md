### `ansible/generate_inventory.sh`

```bash
#!/usr/bin/env bash
# Generate Ansible inventory from Terraform outputs.
# Run from the project root directory.

set -euo pipefail

TERRAFORM_DIR="./terraform"

WS1_FIP=$(terraform -chdir="$TERRAFORM_DIR" output -raw webserver1_floating_ip)
WS2_FIP=$(terraform -chdir="$TERRAFORM_DIR" output -raw webserver2_floating_ip)
LB_FIP=$(terraform -chdir="$TERRAFORM_DIR" output -raw loadbalancer_floating_ip)

WS1_PRIV=$(terraform -chdir="$TERRAFORM_DIR" output -raw webserver1_private_ip)
WS2_PRIV=$(terraform -chdir="$TERRAFORM_DIR" output -raw webserver2_private_ip)

cat > ansible/inventory.ini <<EOF
[webservers]
webserver1 ansible_host=${WS1_FIP} private_ip=${WS1_PRIV} server_id=1
webserver2 ansible_host=${WS2_FIP} private_ip=${WS2_PRIV} server_id=2

[loadbalancer]
loadbalancer ansible_host=${LB_FIP} webserver1_private_ip=${WS1_PRIV} webserver2_private_ip=${WS2_PRIV}
EOF

echo "Inventory written to ansible/inventory.ini"
```

## Deployment Instructions

### Prerequisites

- Terraform >= 1.3 installed
- Ansible >= 2.12 installed
- OpenStack credentials (auth URL, project, username, password)
- An SSH keypair already registered in OpenStack
- `python3-openstackclient` (optional, for verification)

### Step 1: Provision Infrastructure with Terraform

```bash
cd terraform

# Create your variables file from the example
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your actual OpenStack credentials and settings
vi terraform.tfvars

# Initialize Terraform
terraform init

# Review the execution plan
terraform plan

# Apply the configuration
terraform apply -auto-approve
```

### Step 2: Generate Ansible Inventory

```bash
cd ..
chmod +x ansible/generate_inventory.sh
./ansible/generate_inventory.sh
```

This reads Terraform outputs and creates `ansible/inventory.ini` with the correct IPs.

Verify the generated inventory:

```bash
cat ansible/inventory.ini
```

Expected output:

```ini
[webservers]
webserver1 ansible_host=<WS1_FLOATING_IP> private_ip=<WS1_PRIVATE_IP> server_id=1
webserver2 ansible_host=<WS2_FLOATING_IP> private_ip=<WS2_PRIVATE_IP> server_id=2

[loadbalancer]
loadbalancer ansible_host=<LB_FLOATING_IP> webserver1_private_ip=<WS1_PRIVATE_IP> webserver2_private_ip=<WS2_PRIVATE_IP>
```

### Step 3: Configure Servers with Ansible

```bash
cd ansible

# Test connectivity first
ansible -i inventory.ini all -m ping

# Run the playbook
ansible-playbook -i inventory.ini playbook.yml
```

### Step 4: Verify Load Balancing

```bash
# Get the load balancer URL from Terraform
LB_URL=$(terraform -chdir=../terraform output -raw lb_url)
echo "Load Balancer URL: $LB_URL"

# Send multiple requests — you should see responses alternating between servers
for i in $(seq 1 6); do
    echo "--- Request $i ---"
    curl -s "$LB_URL"
    echo ""
```

```
         ── Internal Network 10.0.1.0/24 ──
```

**Key design decisions:**

- `delete_default_rules = true` ensures Terraform fully manages security group rules, with explicit egress rules added per the OpenStack/Terraform best practice from the context.
- Ports `80` and `8082` are defined as Terraform variables (`webserver_port`, `lb_port`) and passed through to Ansible via `group_vars/all.yml`, ensuring a single source of truth.
- Web servers accept HTTP only from `internal_network_cidr`, preventing direct external access on port 80.
- The load balancer has no rule for port 80 — only port 8082 is exposed externally.
- Credentials reside in `terraform.tfvars` (gitignored) and are marked `sensitive` in variable declarations.
